xone-windows-wireless — automatic C++ background preview

Keep the external 045E:02FE adapter connected during Setup. Setup prepares the
verified Microsoft RAM firmware and signed USBip dependency, backs up the stock
binding and selects Microsoft's WinUSB driver. Windows administrator approval
and Internet access can be needed. The first USBip installation briefly restarts
USB hubs; Windows can request a reboot.

The application has no control window, tray icon or overlay. It starts in the
user session at sign-in, recognizes the supported controller/headset models,
connects them and selects the connected headset for audio. Normal operation uses
C++ executables, with no Python runtime, resident PowerShell or text logs.

This remains an experimental user-mode USB/GIP bridge tested on one development
PC. It is not a new Xbox kernel driver. Firmware updates require a real USB cable.

Uninstall restores only a stock binding owned by this installation. Keep the
adapter connected. Shared USBip and private recovery data are retained.
