xone-windows-wireless - C++ bridge alpha.5

Keep the external 045E:02FE adapter connected during Setup. Setup prepares
verified adapter RAM firmware, the signed USBip dependency and system WinUSB.
UAC, internet access, adapter reconnect or a reboot may be required. The first
USBip installation can briefly restart USB hubs.

Devices are detected automatically. The invisible C++ host starts at user sign-in;
no Python runtime or resident PowerShell is installed. Choose headset audio in
Windows or your application. Connecting another headset does not change defaults.

Do not update headset/controller firmware through this bridge, including OTA
updates offered by Xbox Accessories. Stop the bridge and use a physical USB data
cable and the manufacturer's update procedure for the real device.

This is an experimental user-mode USBIP/GIP bridge tested on one PC. Project
executables are unsigned. Stock wireless security parity, controller audio-jack
streaming and full lifecycle reliability are not established. See docs/LIMITATIONS.md.

Uninstall restores only a stock binding owned by this installation. Keep the
adapter connected and retain recovery data. Shared USBip is not removed.
